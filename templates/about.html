About Automobile Price Prediction

Project Overview

This project predicts the estimated price of an automobile using Machine Learning.Users enter car details and the trained model predicts the expected car price

Project Objective

  • Predict automobile prices using Machine Learning.
  • Provide a simple and user friendly interface.
  • Help users estimate car prices quickly

Technology Stack

  • Python
  • Machine Leraning
  • Flask
  • HTML
  • CSS

Dataset Information

  • Dataset Name:Automobile Dataset
  • Total Records:205
  • Input Features:4
  • Target Variable:Price

Future Enhancements

  • Use a modern automobile dataset to improve prediction accuracy.
  • Impliment advanced machine learning algorithms.
  • Deploy the application on the cloud for public access.
  • Integrate real-time automobile market data using APIs
  • Continuously retain the model using updated datasets for better performance.
